原文表题限定“清代所定東方二十八星宿之距星與西方星座之對照”。本版在六张卡片中用中英文说明这一文献范围，保持代表星导览语义，不将清代距星对照扩展为历朝一致的边界、成员或连线。2017年鉴中 Algenib 的“γ Pen”是排印问题，未用于本次壁宿映射。

数值复核使用 CDS/SIMBAD 和[里尔大学保存的 VizieR V/53A 星表输出](https://astronomie.univ-lille.fr/fileadmin/user_upload/astronomie/documents/ateliers/28135_stars.pdf)，与六项既有坐标的球面间距约 0.3–1.5 角秒。名称资料不被当成坐标来源。本轮不更新星表数值、颜色、亮度或连线。

## 行为与性能范围

- 已映射宿从 5 增至 11；所有文化条目仍为 34 个，仍有 17 宿明确未映射
- 六颗星已存在于星图，选择时仅复用原有金色圆环和地平裁剪
- 没有增加恒星、3D 标签或路径采样，没有改动时钟、天体运动、材质、可见性规则、显示开关或逐帧计算
- 新增普通 DOM 文案只在展开并选择对应卡片时展示；继续使用原来的 memo/store 订阅隔离
- 保留中文、Bayer 编号搜索；室、觜、星另可通过已有专名 Markab、Meissa、Alphard 搜索

## 回归

新增回归断言六项身份、原始赤经赤纬、来源限定、搜索结果、四种语言/星图组合的真实代表星对象复用、卡片中英文文献范围；胃宿继续覆盖未映射行为。

完整检查已通过：`npm run test`（36 项，0 失败）、`npm run check`、`npm run lint`、`npm run build`、`git diff --check`。独立审查指出的 SSR 测试初始快照问题已修正并复核；另在真实 R3F 的 stub renderer 下逐一检查六宿切换为 1 个圆环、切胃宿清为 0 个圆环，暂停 demand 调度随后归零。

生产 UI 回归及截图随交付包保存；云浏览器 WebGL 不可用，DOM 验收不代表新增圆环的真实 GPU 画面已验收。本轮不宣称新的 FPS 提升，保留上一轮性能优化结果及其测量边界。
