## 生产构建性能对照

设备：Apple M4 Pro。CSS 视口 1280×720，Canvas 1920×1080；纽约预设，1x 播放，中国星官，全图层开启。旧版使用修改前保存的生产构建；两边先进入稳定状态再采样 5 秒。日期取各次测试的“现在”，相隔数分钟，因此绘制对象数量可能有小幅变化。

临时脚本统计主 Canvas 的 WebGL 调用，以及 256×256 月相图片生成次数；没有将插桩代码写入应用或发布。

| 5 秒窗口 | 优化前 | 最终版本 |
| --- | ---: | ---: |
| 播放时 bufferData/bufferSubData 调用 | 101,785 | 0 |
| 播放时月相图片生成 | 290 | 0 |
| 播放时 texImage2D/texSubImage2D 调用 | 290 | 0 |
| 播放时绘制调用 | 149,400 | 148,800 |
| 暂停稳定后的绘制调用 | 149,400 | 0 |
| 播放时 RAF 间隔 P95 | 9.2ms | 8.5ms |

两边 RAF 频率均约 120Hz，采样窗口没有超过 50ms 的长任务。这验证了持续上传、生成纹理和静止绘制的重复开销已被移除，不能据此推断低端设备的 FPS 提升比例。缓冲区调用次数也不等于上传字节数或 GPU 耗时。高速播放、天体跨越地平线、换年和用户输入仍可能合理地更新部分几何与文字资源。

当前仍是地心几何天空模型，未加入站心视差、大气折射或肉眼可见性模型。银河预生成、标签分级与功能扩展属于后续阶段。
